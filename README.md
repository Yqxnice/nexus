# Nexus 新标签页（MV3 骨架）

一个用原生 HTML/CSS/JS 编写的 Chrome / Edge 新标签页扩展骨架：接管新标签页，提供图标宫格、壁纸、时钟、搜索与待办。无框架、无构建步骤、无网络依赖，`加载已解压的扩展程序` 即可运行。

## 功能

- **新标签页接管**：`chrome_url_overrides.newtab` 指向 `newtab.html`
- **图标宫格**：添加、编辑、删除站点；基于 SortableJS 的拖拽排序（支持跨分类与触屏）；右键图标弹出菜单（打开 / 编辑 / 删除）
- **分类**：站点按分类分组展示，支持添加、重命名、删除分类（删除后站点移入"常用"）；添加/编辑站点时可选择所属分类
- **壁纸**：6 套内置 CSS 渐变壁纸（极光 / 深海 / 日落 / 森林 / 紫夜 / 石墨），完全离线；支持添加本地图片壁纸（自动压缩后存入扩展存储，可一键移除）
- **小组件**：数字时钟 + 中文日期、带搜索引擎切换的搜索框（支持网址直达）、待办清单（增删勾选、清除已完成、进度条）
- **设置抽屉**：主题（跟随系统 / 浅色 / 深色）、壁纸、默认搜索引擎、打开方式、添加分类入口、重置数据
- **持久化**：扩展内使用 `chrome.storage.local`（`chrome.storage.local` 默认约 10MB，本地图片壁纸经 canvas 压缩：最长边 2560px、JPEG 质量 0.85，超出体积会自动降质或拒绝）；普通网页预览时自动回退 `localStorage`
- **体验细节**：中文界面，深浅色主题，响应式布局，细圆角滚动条，状态按需重渲染、拖拽期间关闭毛玻璃以保证流畅，离线可用

## 目录结构

```text
nexus/
├─ manifest.json          # MV3 清单，仅申请 storage 权限
├─ newtab.html            # 新标签页入口（交付物）
├─ css/
│  ├─ base.css            # 设计变量、主题、壁纸、页面布局、通用按钮
│  └─ components.css      # 时钟、搜索、宫格、待办、设置、对话框、toast
├─ js/
│  ├─ app.js              # 入口：初始化组件、全局快捷键、离开页面时落盘
│  ├─ state.js            # 默认数据、状态校验、订阅式 Store
│  ├─ storage.js          # chrome.storage.local + localStorage 回退
│  ├─ time.js             # 时钟与日期
│  ├─ search.js           # 搜索 / 网址直达 / 搜索引擎切换
│  ├─ shortcuts.js        # 图标宫格 CRUD 与拖拽排序
│  ├─ todos.js            # 待办清单
│  ├─ settings.js         # 设置抽屉、主题与壁纸
│  ├─ ui.js               # toast、确认对话框
│  ├─ utils.js            # DOM、URL、ID、打开链接等工具
│  └─ vendor/
│     └─ sortable.min.js  # SortableJS 1.15.6（MIT，本地内置，无网络请求）
├─ assets/icons/          # 16/32/48/128 PNG 图标
└─ README.md
```

## 加载方式

### Chrome

1. 地址栏打开 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择目录 `E:\AdminOS\nexus`
4. 打开任意新标签页，应看到 Nexus 仪表盘而不是默认空白页

### Edge

1. 地址栏打开 `edge://extensions`
2. 打开左侧/左下角「开发人员模式」
3. 点击「加载解压缩的扩展」，选择目录 `E:\AdminOS\nexus`
4. 打开新标签页验证

> 如果浏览器里还启用了其他接管新标签页的扩展（如 iTab、Infinity），请先停用其中一个，浏览器同一时间只允许一个扩展覆盖新标签页。

### 本地预览（非扩展环境）

ES 模块不能用 `file://` 直接打开。可在项目目录运行静态服务器后访问：

```powershell
python -m http.server 8123
# 然后打开 http://127.0.0.1:8123/newtab.html
```

此时页面自动使用 `localStorage` 回退，其余交互与扩展环境一致。

## 验证清单

1. 打开新标签页，时钟每秒更新，日期为中文
2. 搜索框回车：普通词跳转搜索引擎；输入 `github.com` 这类网址则直达
3. 直接拖拽任意图标到另一位置可排序；拖到其他分类区域可跨分类移动；刷新后顺序保留
4. 右键点击任意图标：弹出"打开 / 编辑 / 删除"菜单，各项可用；左键点击图标仍是直接打开站点
5. 点击"添加分类"新建一个分类；悬停分类标题可向该分类添加站点、重命名或删除分类
6. 点击某个分类区域的"添加站点"，保存后新站点落在该分类下；刷新后仍在
7. 点击右上"壁纸"，在设置抽屉中切换任意壁纸；壁纸立即生效；点击"本地图片"卡片选择一张本地图片，壁纸切换为该图（卡片显示缩略图），卡片右上角 × 可移除
8. 点击右上"主题"，或在设置中切换"跟随系统 / 浅色 / 深色"；界面配色立即变化
9. 添加、勾选、删除待办，点击"清除已完成"；刷新后状态保留
10. 打开设置抽屉滚动、切换主题/壁纸，操作应流畅无明显掉帧
11. 打开 DevTools Console，确认无报错（搜索、打开外链需要联网，属正常行为）

## 权限与数据

- 仅声明 `permissions: ["storage"]`；**没有** `tabs`、`history`、`<all_urls>` 等主机权限
- 内置第三方库：SortableJS 1.15.6（MIT 许可），已本地打包于 `js/vendor/`，运行时无任何网络请求
- 不请求 favicon、天气、统计等外部资源；图标使用首字母色块
- 所有数据存于本机：`chrome.storage.local` 键名 `nexus_state_v1`，不会上传
- 站点 URL 仅接受 `http` / `https`，拒绝 `javascript:`、`data:` 等危险协议
- 删除扩展会一并删除扩展存储的数据

## 限制与风险

- 这是**骨架级**实现：没有账号同步、云备份、天气、导入导出、全局快捷键；分类支持增删改与跨分类拖拽，但分类本身暂不支持拖拽排序
- 拖拽基于 SortableJS（本地内置），桌面与触屏均可排序；分类本身暂不支持拖拽排序
- 无痕窗口默认不加载该扩展（需在扩展详情中手动允许）
- 新标签页被接管后，浏览器原生的快捷入口（如部分书签栏行为）会被替换
- 直接双击 `newtab.html` 无法运行（ES 模块受 `file://` 限制），请按上面的方式加载扩展或使用本地服务器
- `chrome.storage.local` 默认配额约 10MB；本地回退受浏览器 localStorage 配额限制
- 若同时启用多个新标签页扩展，浏览器只会使用其中一个，可能出现“设置后不生效”的观感

## 后续扩展建议

- 将每个小组件（如天气占位、书签、日历）拆成独立 `js/widgets/*.js`，在 `app.js` 中注册
- 如需网络型小组件，在 `manifest.json` 中按最小域名添加 `host_permissions`，并将请求逻辑封装成独立模块
- 如需导入/导出，可直接读写 `nexus_state_v1` 这一个 JSON 状态对象
